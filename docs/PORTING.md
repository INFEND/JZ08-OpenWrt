# Порт JZ08: аппаратные и программные критерии

Это инженерный проект, а не прошивка для установки.

## Доказано ранее
- Qualcomm MSM8916, Android 4.4.4, 27 GPT, eMMC 3 909 091 328 байт.
- p14 = modemst2, p22 = boot (16 МиБ), p23 = system (800 МиБ), p26 = recovery, p27 = userdata.
- EDL: чтение полной eMMC; запись и обратное SHA-256 чтение recovery p26.
- LK2ND 0.5 запущен, Fastboot PID 18d1:d00d работает.
- Linux 6.12 Image передан через fastboot boot; исполнение Linux init неизвестно.
- OEM DT упоминает ST7735S и NV3023A (128x128), SPI4, GPIO116/118.

## Необходимо завершить
1. Внести очищенные от секретов актуальные инженерные исходники v27-v36 из полного XARKON handoff, проверить происхождение и контрольные суммы.
2. Портировать QCDT v2 (8 записей, board IDs 8/0 и 8/256), корректные RAM-адреса, USB, eMMC и доказать исполнение /init.
3. Установить физическую LCD-модель, GPIO DC/reset, полярности, PMIC WLED, питание, SPI4.
4. Собрать и проверить драйверы LTE/QMI/RMTFS, Wi-Fi, кнопки, аккумулятор, USB gadget.
5. Спроектировать и проверить карту rootfs под OEM GPT без замены заводской GPT, загрузчиков и NV-разделов.
6. Отладить откат затрагиваемых разделов с фактическим readback.
7. Проверить на реальном устройстве Linux, LuCI по-русски, SIM, LTE, Wi-Fi, USB, LCD, перезагрузки и сохранение настроек.
8. Только затем создавать Flash ZIP для root Samsung S24 Ultra с Termux.

## Запреты
- Никогда не запускать generic-mf68e flash.sh или перенос чужой GPT.
- Не писать p14/modemst2 и другие разделы NV, калибровок, загрузчиков.
- Не включать LCD DTS до подтверждения физического контроллера.
- Не публиковать заводской дамп (может содержать IMEI/NV/ключи).
- Нельзя назвать образ production/flashable только на основании компиляции.
