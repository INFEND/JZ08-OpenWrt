# INFEND JZ08 — полный OpenWrt RAM-комплект v1

В комплекте настоящее ядро Linux 6.12.58, полный OpenWrt initramfs с его
совпадающими модулями, русский LuCI, SSH, сетевые службы, ModemManager/rmtfs,
исходный system.img и автоматическая цепочка S24. Это полная система для
первого испытания в RAM. Постоянная установка пока не готова: Linux/OpenWrt
на физической JZ08, радио, LCD и схема постоянной загрузки ещё не проверены.

Сохрани `INFEND_JZ08_OPENWRT_FULL_TRIAL.zip` в Download и запусти в Termux:

```bash
python /storage/emulated/0/Download/INFEND_JZ08_OPENWRT_FULL_TRIAL.zip --ram-test
```

Требуются прежнее рабочее окружение S24/Magisk/Termux/EDL, USB-OTG и уже
сохранённый полный заводской backup. Его размер/SHA и обе GPT проверяются;
повторный многогигабайтный backup не создаётся и никуда не загружается.

При необходимости вход в LK2ND временно записывает **только recovery p26**,
с точной проверкой диапазонов и чтением назад. После испытания выполняется
попытка вернуть factory p26 и проверить SHA-256. При потере USB может
потребоваться ручной перезапуск устройства. Питание во время записи не отключать.

Адреса соответствуют машинному коду сохранённого LK2ND: ядро `0x80000000`,
DTB `0x81e00000`, initramfs `0x82000000`. Используется небольшое ядро без
встроенного rootfs и отдельный сжатый полный initramfs. Перекрытия запрещены.
Реальная RAM читается из OEM DTB загрузчика перед запуском; размер 512 МиБ
не предполагается. Результат статического анализа — в `board/evidence` репозитория.

Система работает около 10 минут и автоматически запрашивает возврат recovery.
USB-LuCI: `http://192.168.73.1/`, логин `root`. Новый случайный пароль каждого
запуска сохраняется **только на S24** в `Download/INFEND_JZ08_ACCESS.txt`.
Скрипт назначает IP `192.168.73.2/24` только USB-интерфейсу с меткой этого запуска.
Если ядро Android не создало RNDIS/ECM интерфейс, это отдельно попадёт в отчёт.
Наличие страницы LuCI не заявляется до её фактического получения.

Служба USB использует совпадающий `g_ether` из этой сборки; CONFIGFS USB
в исходном ядре выключен. Для первого испытания remoteproc/Wi-Fi, LED/GPIO
потребители выключены в DTB. Драйверы и службы радио остаются в комплекте,
но их наличие не является проверкой LTE/Wi-Fi. Чужие firmware/NV не включены.
Весь видимый набор eMMC block devices до запуска procd переводится в RO;
ядро не получает root= на OEM-раздел. Настройки данного сеанса хранятся в RAM.

Один отчёт `INFEND_JZ08_OPENWRT_REPORT_*.zip` сохраняется в
`Download/XARKON_JZ08_REPORTS/`. В нём отдельно отмечаются `/init`, OpenWrt,
USB, HTTP LuCI, геометрия eMMC и восстановление p26. `--verify` повторно
проверяет текущий сеанс. `--selftest` проверяет ZIP без оборудования.

Если автоматический возврат factory recovery не подтвердился, верни доступный
USB/EDL и запусти тот же ZIP с `--restore`. BOOT/SYSTEM/GPT этот инструмент
не записывает. `--flash` заблокирован до независимого аппаратного результата
и разработки постоянной boot chain. Включённый исходный system.img имеет
пометку UNCONFIGURED и не предназначен для прямой записи.

Источники, точные версии и все преобразования находятся в репозитории
https://github.com/INFEND/JZ08-OpenWrt. Сборка rootfs: OpenWrt
`46ab9f3f1c0e6ac2a17efa5a3f34e466a0c2d4e0`, msm89xx
`c2e2dd5afc6ec4e8be55cfc952a1fce042e681c4`. SHA производителя и всех
полученных файлов включены в архив. Аппаратная готовность не подменяется
успешным офлайн-аудитом.
